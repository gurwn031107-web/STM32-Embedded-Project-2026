# STM32 4WD 자율주행 RC카 (미니 프로젝트)

NUCLEO-F411RE와 FreeRTOS로 만든 4WD RC카입니다.
초음파 센서 3개(왼쪽, 중앙, 오른쪽)로 앞과 옆의 벽까지 거리를 재서, 앞이 막히면 넓은 쪽으로 돌아 피하고 벽 사이에서는 가운데를 따라 달립니다.
버튼과 PC 터미널로 자동 주행과 수동 주행을 바꿀 수 있습니다.

- 기간: 2026.11.12 ~ 2026.11.15
- 보드: NUCLEO-F411RE (STM32F411RE, 100MHz)
- RTOS: FreeRTOS (CMSIS-RTOS v1)

## 기능

| 기능 | 설명 |
|---|---|
| 자동 주행 | 1번 버튼이나 PC의 `AUTO*` 명령으로 바로 출발. 전방 회피, 측면 회피, 벽 사이 가운데 유지 |
| 수동 주행 | 2번/3번 버튼으로 좌/우 회전, PC 터미널 `RUN*`, `STOP*`, `SPD<속도>*`로 출발, 정지, 속도 변경 |
| 비상 정지 | 자동 주행 중 아무 버튼이나 누르면 수동 모드로 돌아가며 바로 정지 |
| LCD | 1줄은 현재 동작(`AUTO FORWARD`, `AUTO SPIN LEFT` 등), 2줄은 왼쪽/중앙/오른쪽 거리 또는 센서 에러 코드 |

## 핀 배치

| 장치 | 핀 | 비고 |
|---|---|---|
| 초음파 중앙 | TRIG PB10, ECHO PA8 | HC-SR04 |
| 초음파 왼쪽 | TRIG PA4, ECHO PB0 | 처음엔 A0/A1에 연결했다가 옮김 |
| 초음파 오른쪽 | TRIG PA10, ECHO PB3 | |
| 왼쪽 바퀴 | PWM PC6 (TIM3 CH1), 방향 PB6, PA7 | |
| 오른쪽 바퀴 | PWM PC8 (TIM3 CH3), 방향 PA5, PA6 | |
| 버튼 | PC0 자동 시작/정지, PC1 왼쪽, PC2 오른쪽 | |
| I2C LCD | PB8 (SCL), PB9 (SDA) | |
| USART2 | PA2, PA3 | 115200bps, PC 터미널 |
| USART6 | PA11, PA12 | 9600bps, 블루투스 모듈용 (코드에서 꺼 둠) |

모터 PWM은 TIM3으로 1kHz(100MHz / 100 / 1000)를 만들고, 속도는 0~999로 줍니다.

## 태스크 구조

| 태스크 | 주기 | 우선순위 | 하는 일 |
|---|---|---|---|
| SensorTask | 측정 후 20ms | AboveNormal | 왼쪽, 중앙, 오른쪽 센서를 15ms 간격으로 번갈아 측정하고 필터를 거쳐 저장, LCD 2줄 표시 |
| MotorTask | 10ms | Normal | 수동 모드면 상태 머신(STOP / RUN / LEFT / RIGHT), 자동 모드면 `auto_drive_update()` 실행 |
| ButtonTask | 10ms | Normal | 1번 버튼은 주행 모드 전환, 나머지 버튼은 `btnQue`로 MotorTask에 전달 |
| CommTask | 1ms | Normal | UART로 받은 명령(`*`로 끝)을 해석해 모드를 바꾸거나 `commQueue`로 전달 |

- `sensorMutex`: SensorTask가 거리 3개를 쓰는 도중에 MotorTask가 읽어서 값이 섞이지 않게 막습니다.
- `lcdMutex`: 네 태스크가 LCD를 같이 써서 한 번에 하나만 쓰게 합니다.
- 주행 모드는 32비트 변수 하나라서 뮤텍스 없이 `volatile`로 공유합니다.
- 초음파는 ECHO 시간을 폴링으로 재기 때문에, 재는 도중에 다른 태스크가 끼어들면 거리가 틀어집니다. 그래서 SensorTask 우선순위를 가장 높게 두었습니다.

## 자동 주행 알고리즘

MotorTask가 10ms마다 아래 순서로 판단합니다.

1. **전방 회피**: 중앙 거리가 20cm보다 가까우면 0.2초 멈춰서 센서 값을 새로 받고, 방향을 정해 제자리 회전합니다. 중앙이 30cm보다 멀어질 때까지 같은 방향으로 돌고, 0.1초 멈춘 뒤 다시 출발합니다.
   - 회전 방향은 (1) 직전 2초 안에 한쪽만 40cm 이상 열렸던 쪽(직각 코너의 출구), (2) 좌우 차이가 10cm 이상이면 더 넓은 쪽, (3) 둘 다 아니면 지난번에 돈 방향 순서로 고릅니다.
   - 시작 기준(20cm)과 끝 기준(30cm)을 따로 둬서, 경계에서 회전과 직진이 계속 바뀌며 차가 떨리는 것을 막았습니다.
2. **측면 회피**: 왼쪽 벽이 10cm보다 가까우면 오른쪽으로, 오른쪽 벽이 27cm보다 가까우면 왼쪽으로 제자리 회전합니다.
3. **직진**: 양쪽 벽이 모두 40cm 안에 있을 때만 좌우 거리 차이로 P 제어를 합니다.
   - 오차 = 왼쪽 거리 - 오른쪽 거리 (±2cm 이내는 무시)
   - 보정값 = 오차 x 15 (최대 ±200)
   - 왼쪽 바퀴 = 900 - 보정값, 오른쪽 바퀴 = 900 + 보정값
   - 한쪽이 열려 있으면 그쪽으로 끌려가지 않도록 그냥 직진합니다.

| 설정 | 값 |
|---|---|
| 직진 속도 | PWM 900 |
| 회전 속도 | PWM 700 |
| 오른쪽 바퀴 보정 | +50 (직진할 때 오른쪽으로 쏠려서 추가) |

## 초음파 측정

- Cortex-M4의 DWT 사이클 카운터로 ECHO가 High인 시간을 잽니다. 100MHz라서 100사이클이 1µs이고, 타이머를 따로 설정하지 않아도 됩니다.
- 측정에 실패하면 10ms 쉬고 최대 3번 다시 잽니다. 그래도 실패하면 LCD에 원인 코드를 띄웁니다.
  - `E1`: TRIG 후 ECHO가 올라오지 않음 (배선, 센서 불량)
  - `E2`: 2m 안에 물체 없음 (에러로 띄우지 않고 200cm로 처리)
  - `E3`: 측정 전부터 ECHO가 High로 멈춰 있음 (센서 전원 다시 연결)
- 필터: 가까워진 값은 바로 반영하고, 멀어진 값은 크게 튀지 않으면 이전 값과 평균을 냅니다. 연속 3번 실패까지는 마지막 정상값을 유지합니다.

## 트러블슈팅

- **왼쪽 센서 민감도 차이**: 왼쪽 센서가 오른쪽보다 둔해서 한쪽 회피가 늦게 됐습니다. 처음엔 배선 문제인 줄 알고 핀을 A0/A1에서 A2/A3(PA4, PB0)로 옮겼지만 그대로였고, 같은 모델이라도 센서마다 반응이 다르다고 판단했습니다. 좌우 회피 기준을 10cm, 27cm로 따로 두고 트랙에서 직접 돌려 보며 맞췄습니다. 센서를 바꾸면 이 값도 다시 맞춰야 합니다.
- **인터럽트 측정**: EXTI 인터럽트 방식도 해 봤는데 값이 0이나 E1로 자주 튀어서 폴링으로 돌아왔고, 대신 SensorTask 우선순위를 높였습니다.
- **직각 코너**: 코너 앞에서 좌우 거리가 비슷하게 나와 엉뚱한 쪽으로 도는 경우가 있어서, 다가오는 동안 열렸던 쪽을 2초간 기억해 먼저 그쪽으로 돌게 했습니다.

## 개선할 점

- 센서 3개를 한 번 다 재는 데 약 70ms가 걸려서 빨리 달리면 반응이 늦습니다. 타이머 Input Capture로 바꿔 기다리는 시간을 줄이고 싶습니다.
- 바퀴 보정값(50)은 고정값이라 속도나 배터리에 따라 달라집니다. 엔코더로 실제 속도를 보고 보정하면 더 정확해질 것 같습니다.
- 블루투스 수신 코드(USART6, `A` 자동 시작 / `S` 정지)는 넣어 두었지만 꺼 두었습니다(`BT_ENABLE 0`). 켜서 휴대폰으로도 자동/수동을 바꿀 수 있게 하는 것이 다음 목표입니다.

## 폴더 구조

```
Core/Src/
├── freertos.c                 # 태스크, 큐, 뮤텍스 생성
├── ap/
│   ├── auto_drive/            # 자동 주행 판단, 바퀴별 속도 출력
│   ├── auto_message.c         # 주행 모드, 거리값 공유 (sensorMutex)
│   ├── message.h              # 버튼 / 통신 큐 메시지
│   └── task/
│       ├── sensor_task/
│       ├── motor_control_task/
│       ├── button_task/
│       └── comm_task/
└── driver/
    ├── ultrasonic/            # HC-SR04, DWT µs 측정
    ├── dc_motor/
    ├── lcd/                   # I2C LCD
    └── button/
```

## 빌드

1. STM32CubeIDE에서 `File > Import > Existing Projects into Workspace`로 폴더 열기
2. `.ioc`를 열고 Generate Code (HAL 드라이버와 FreeRTOS 소스는 저장소에서 제외)
3. Build 후 Run
