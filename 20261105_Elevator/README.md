# STM32 3층 엘리베이터 (미니 프로젝트)

스텝모터와 포토 인터럽터로 만든 3층 엘리베이터입니다.
버튼으로 층을 부르면 스텝모터가 카를 움직이고, 층마다 붙인 포토 인터럽터로 위치를 확인해 그 층에 멈춥니다.

- 발표 자료: [STM32_Elevator_발표자료.pptx](docs/STM32_Elevator_발표자료.pptx)
- PC 프로그램: [pc_gui](pc_gui)
- 보드: NUCLEO-F411RE (STM32F411RE, 100MHz)

## 기능

| 기능 | 설명 |
|---|---|
| 층 호출 | 버튼 3개로 층을 부름, 이동 중에 누르면 비상 정지 |
| 도착 알림 | 딩(1319Hz, 0.3초), 동(1047Hz, 0.6초)을 울리고 2초 뒤 문 LED가 3초간 켜짐 |
| LCD | 1줄은 `FLOOR:1F > 3F UP`처럼 현재 층, 목표 층, 방향 / 2줄은 엘리베이터 안 온습도 |
| PC 프로그램 | UART로 층 호출, 비상 정지, 원점 복귀, 상태 표시 |
| 원점 잡기 | 전원을 켜면 1층 센서까지 내려가 위치를 0으로 맞춤 |

## 핀 배치

| 장치 | 핀 | 비고 |
|---|---|---|
| 층 버튼 x3 | PC0, PC1, PC3 | active-low |
| 포토 인터럽터 x3 | PC2(1층), PC10(2층), PB12(3층) | 가리면 HIGH |
| 28BYJ-48 + ULN2003 | PA0, PA1, PA4, PB0 | 풀스텝 |
| 부저 | PA11 | TIM1 CH4 PWM |
| 문 LED | PB15 | |
| DHT11 | PC8 | 1-wire |
| I2C LCD 1602 | PB8(SCL), PB9(SDA) | 주소 0x27 |
| USART2 | PA2, PA3 | 115200bps, PC 프로그램 통신 |

모터는 전류가 커서 외부 5V 전원을 따로 쓰고 GND만 보드와 공통으로 연결했습니다.

## 상태 머신

| 상태 | 동작 |
|---|---|
| `HOMING` | 전원을 켜면 아래로 내려가 1층 센서에서 위치를 0으로 잡음 |
| `IDLE` | 층 버튼이나 PC 명령을 기다림 |
| `MOVING` | 목표 층 센서가 60스텝 연속으로 가려지면 정지, 지나가는 층은 현재 층만 바꿈 |
| `DOOR` | 딩동 후 문 열림, 5초 뒤 닫힘. 그 사이 누른 층은 기억했다가 출발 |
| `ERROR` | 타임아웃(15,000스텝), 비상 정지, 너무 빠른 도착(센서 이상) 시 정지. 아무 버튼이나 누르면 원점부터 다시 시작 |

## 구현하면서 신경 쓴 부분

- TIM3 인터럽트가 2ms마다 모터를 1스텝 움직이고 바로 센서 3개를 읽습니다.
- 처음에는 센서가 가려지는 순간 멈췄는데, 차광판 끝이 센서 경계에 걸려 값이 계속 흔들렸습니다. 60스텝(0.12초) 연속으로 가려질 때만 도착으로 인정하도록 바꿔서 경계보다 안쪽에서 멈추고 짧은 잡음도 무시하게 했습니다.
- 부저와 문은 `HAL_Delay` 없이 도착 후 지난 시간으로 단계를 넘겨서, 모터와 LCD 갱신을 막지 않습니다.
- DHT11은 µs 단위 타이밍이 민감해서 카가 멈춰 있을 때만 2초마다 읽습니다.
- 1층에서 3층까지 약 9,000스텝(약 18초)이 걸립니다.

## UART 명령

- PC에서 보드로: `CALL 1` ~ `CALL 3`, `STOP`, `HOME`
- 보드에서 PC로: `$ST,<상태>,<현재층>,<목표층>,<방향>,<위치>,<문>,<센서>,<에러>`

```
pc_gui/                      # PySide6 PC 프로그램
docs/                        # 발표 자료
```
